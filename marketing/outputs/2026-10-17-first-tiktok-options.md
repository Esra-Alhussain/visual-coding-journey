## Option C — From knowing the output to using the idea

Angle: a tiny learning interaction followed by a question about transfer to a real task. Hypothesis: an example makes the learning discussion concrete, but a loop example may bias replies toward loops.

### Hook

AR: ماذا يطبع هذا الكود؟ خذ لحظة قبل أن أُظهر الناتج.

EN: What does this code print? Take a moment before I reveal it.

Code shown exactly, with indentation:

```python
for i in range(3):
    print(i)
```

### CTA/question

### Learning goal

Student: predict a basic loop's output and see the exclusive stop value. Team: explore the gap between following examples and applying concepts. Correct predictions or comments alone do not demonstrate a learning improvement.

Production needs: founder recording plus code/output text graphics. No game code changes or Python-runtime integration required.

## Choosing a first post

Recommend A for this request's discovery goal: it asks about a recent experience without first defining the problem for students. B introduces the founder's purpose most explicitly. C gives immediate educational value but steers attention toward applying examples and loops. These are editorial judgments, not proven performance predictions.

Select one for review and recording. This is not a controlled A/B/C experiment; posting all three at different times would not isolate the cause of response differences.
