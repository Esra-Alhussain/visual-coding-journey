What to try

  1. Tap Mochi in the welcome, then follow the introduction.
  2. Run the three-jump demonstration and begin the first mission.
  3. Type in the empty editor, open a hint and inspect sample feedback.
  4. Explore the map, mini show and optional account presentation.
  5. Use the Home control to return to the opening.

These are design prototypes: the welcome demo animates, navigation and feedback controls work. Learner code execution, real speech, assessment and accounts belong to the working app.
