# Three little beginnings

Open index.html in a browser. No installation, server, account or network needed. Try Garden, Bridge and Café, including a wrong number, Hint, 3, Replay and Compare worlds. Notes stay on your browser; Download notes exports them for your own review.

Authorized by owner on 2026-10-18 as a separate three-way interactive concept comparison. No final world or curriculum selected. Each mission uses the same number-assignment puzzle and target 3. Safe simulation, not a Python interpreter. Illustrated backgrounds are generated; foreground characters and reactions are simplified CSS/emoji concept animation, not final game assets. Sound and bilingual UI are outside this comparison.

Art: concepts.png, generated with built-in imagegen. Brief: equal-width garden, missing bridge and café terrace triptych; consistent warm storybook illustrated game environment, no characters or text. Final exact prompt retained in art-prompt.txt.

Validation: node devpost/world-comparison/check.cjs. DOM simulation covers three missions, invalid and wrong values, hints, success, replay and saved notes. Actual browser visual/mobile QA remains pending because browser runtime failed to start. No deployment or external publication.
