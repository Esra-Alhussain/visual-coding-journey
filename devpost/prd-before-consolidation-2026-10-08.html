The bigger direction · agreed

Build a place through growing coding skills. As learners become more capable, they bring their own creations to life and progress toward independent projects. The exact world design stays open: a town or a character is optional.

The first build remains one tiny-shop journey. Conditions, loops, functions, and connected creations are possible later stages, not additions to this build.

Introduction & first lesson

A parcel unfolds into an unfinished shop and previews code changing its appearance. “Create my shop” leads to naming and shop choice before the map.

The sign-maker lesson connects a name variable to a blank sign, then lets the learner edit the name themselves. Exact shop options and map progression remain open.

Stock · explain the boundary naturally

For unsupported items: “Cake isn't in our stock. Try another item from the tray.” Keep data-versus-drawing teaching separate. Exact stock and tray design remain open; placeholders have not been approved.

Errors · learn to debug

When code cannot run, dim the shop: “Your shop couldn't update—check the highlighted line.” Explain the correction and let the learner make it. Fixing the code restores the live result.

Reflect actual consequences. Code that runs but produces an unexpected result should not be treated as a failure to run.

AI · stories connected to their shop

Frame a small coding task using the learner's shop choices. Retell a confusing concept as a mini shop story when help is requested. The learner writes the code.

Help controls and unavailable-help behavior still need agreement. Broader adaptive learning is not part of the first build.

Challenge & reflection

Agreed challenge: rename the shop, change its wall color, and replace one product without step-by-step instructions. Help remains available on request.

Finish with a short reflection on progress. Completion checks and reflection interaction remain open; personalized next-project generation is deferred.

Full curriculum, GitHub syncing, checkout, additional formats, and personalized next journeys remain future work.
