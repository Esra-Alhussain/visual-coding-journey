Python and its tools
Python is a language for giving computers instructions. Here you practise in a game editor: write your code, press Run and read the Output panel.
Outside this game, Python executes your program. IDLE and Jupyter are examples of tools for writing and trying Python. In interactive mode you try instructions and see results directly; in script mode you save instructions in a .py file and run it.
The interpreter executes the program; an editor helps you write it. This experience supports a limited Python subset: text, numbers, assignment, print, addition, subtraction, multiplication, parentheses and comments. It is not a full Python runtime or complete course coverage.
